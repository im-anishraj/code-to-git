# Contributing to Leet to Git

First off, thank you for considering contributing to Leet to Git! It's people like you that make this tool awesome for the developer community.

## How can I contribute?

### 1. Reporting Bugs
This section guides you through submitting a bug report. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.
- Use the GitHub Issues tab to report bugs.
- Explain the problem and include additional details to help maintainers reproduce the problem.
- Include screenshots or animated GIFs if possible.

### 2. Suggesting Enhancements
This section guides you through submitting an enhancement suggestion, including completely new features and minor improvements to existing functionality.
- Open a new Issue and use the "Enhancement" label.
- Provide a clear and descriptive title.
- Describe the current behavior and the behavior you want to see.

### 3. Submitting Pull Requests
1. Fork the repo and create your branch from `main`.
2. Run `npm install` to install dependencies.
3. Make your changes in the codebase.
4. Run `npm run build` to ensure the project builds correctly.
5. Test your changes by loading the extension locally (see README for local development setup).
6. Ensure your code follows the existing style (`npm run format` and `npm run lint`).
7. Open a Pull Request with a clear description of your changes!

## Development Setup
Check out the `README.md` for detailed instructions on how to set up the extension locally on your machine for development.

Thank you for contributing! 🚀
